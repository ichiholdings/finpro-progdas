# finpro-progdas
repo bagi finpro kelompok artemis

Tema dari program kami berasal dari SDG ke-12 yang berupa ‘Reasonable Consumption and Production’. Tujuan dari produk kami adalah untuk menjunjung tinggi aspek reasonable consumption dari SDG ini. Program kami tepatnya diaplikasikan di TPA dimana user dapat mengakses interfacenya untuk mendaur ulang sampah berdasarkan jenis sampah.
Program kami berupa sebuah interface yang user dapat interaksi. Pada program kami terdapat fitur akun user yang menyimpan runtunan mendaur ulang sampah serta menyimpan poin dalam akun. Saat user mendaur ulang sampah, user akan diberi pilihan mengenai jenis sampah yang dibuang. Setiap jenis sampah ini memiliki imbalan poin yang berbeda-beda. Pendapatan poin user juga terefek oleh runtunan yang dimiliki oleh user. Lebih seringnya user mendaur sampah maka lebih banyak imbalan poin. Poin yang sudah dikoleksi oleh user ini dapat ditukar untuk voucher ataupun merch yang berupa hasil dari pendaur ulangan sampah.
Dengan program kami kami berharap masyarakat dapat mengubah kebiasaan, perilaku, serta pandangan mereka terhadap pendaur ulangan. Barang yang didaur ulang bukanlah barang yang memiliki nilai kurang dari barang dari bahan mentah. Barang yang didaur ulang memiliki nilai tersendirinya yang tidak kalah dibanding dengan barang baru jadi. Dengan memberi insentif kepada masyarakat untuk mengubah kebiasaannya kita dapat mengurangi sampah yang dibuang ke dalam lingkungan ataupun TPA. Dengan insentif berupa barang hasil dari daur ulang kami berharap masyarakat dapat membuka matanya terhadap nilai dari benda hasil daur ulang.
